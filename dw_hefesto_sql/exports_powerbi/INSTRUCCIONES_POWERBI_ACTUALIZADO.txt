📈 NUEVAS VISUALIZACIONES POSIBLES
================================================================================

Con la nueva dimensión, ahora puedes crear:

1. ANÁLISIS TEMPORAL DE ESCASEZ DE AGUA

   Gráfico de Líneas:
   - Eje X: DIM_GEOGRAFIA[Anio]
   - Eje Y: Conteo (para ver cuántos países)
   - Leyenda: DIM_GEOGRAFIA[Nivel_Escasez_Agua]

   Esto muestra cómo ha evolucionado la escasez globalmente

2. IMPACTO POR NIVEL DE ESCASEZ

   Gráfico de Barras Agrupadas:
   - Eje Y: DIM_GEOGRAFIA[Nivel_Escasez_Agua]
   - Eje X: Total Huella Hídrica
   - Segmentar por: Año o País

   Muestra el consumo de IA en regiones con diferentes niveles de escasez

3. MAPA DE CALOR: País × Año × Escasez

   Matriz:
   - Filas: DIM_GEOGRAFIA[Pais]
   - Columnas: DIM_GEOGRAFIA[Anio]
   - Valores: DIM_GEOGRAFIA[Nivel_Escasez_Agua]
   - Formato condicional:
     * Low = Verde
     * Moderate = Amarillo
     * High = Rojo

4. PAÍSES CON MAYOR RIESGO

   Tabla filtrada:
   - Filtro: Nivel_Escasez_Agua = "High"
   - Mostrar: País, Año, Total Huella Hídrica
   - Ordenar: Descendente por Huella

   Identifica zonas críticas donde el uso de IA agrava problemas de agua

================================================================================
🎯 MEDIDAS DAX ADICIONALES
================================================================================

// Consumo en Países con Alta Escasez
Consumo en Alta Escasez =
CALCULATE(
    [Total Huella Hídrica],
    DIM_GEOGRAFIA[Nivel_Escasez_Agua] = "High"
)

// Porcentaje de Sesiones en Zonas de Escasez
% Sesiones en Escasez =
VAR TotalSesiones = [Total Sesiones]
VAR SesionesEscasez =
    CALCULATE(
        [Total Sesiones],
        DIM_GEOGRAFIA[Nivel_Escasez_Agua] IN {"High", "Moderate"}
    )
RETURN
DIVIDE(SesionesEscasez, TotalSesiones, 0)

// Indicador de Riesgo (combina consumo y escasez)
Índice de Riesgo Hídrico =
VAR Consumo = [Total Huella Hídrica]
VAR Escasez =
    SWITCH(
        SELECTEDVALUE(DIM_GEOGRAFIA[Nivel_Escasez_Agua]),
        "Low", 1,
        "Moderate", 2,
        "High", 3,
        0
    )
RETURN
Consumo * Escasez

// Evolución de Escasez (comparación anual)
Cambio en Escasez =
VAR AnioActual = SELECTEDVALUE(DIM_GEOGRAFIA[Anio])
VAR AnioAnterior = AnioActual - 1
VAR EscasezActual = SELECTEDVALUE(DIM_GEOGRAFIA[Nivel_Escasez_Agua])
VAR EscasezAnterior =
    CALCULATE(
        SELECTEDVALUE(DIM_GEOGRAFIA[Nivel_Escasez_Agua]),
        DIM_GEOGRAFIA[Anio] = AnioAnterior
    )
RETURN
IF(EscasezActual = EscasezAnterior, "Sin Cambio", "Cambió")
